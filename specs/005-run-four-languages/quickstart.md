# Nghiệm thu chạy mã

Khởi động Docker Desktop, sau đó tạo image bằng lệnh docker build -f Dockerfile.grader -t fit-tutor-grader:1 . tại thư mục dự án. Chạy lại server để có endpoint mới.

Ở mỗi ngôn ngữ, chạy Hello World và chương trình đọc 2 số từ stdin rồi in tổng. Thử lỗi cú pháp, chia 0 hoặc ngoại lệ runtime và vòng lặp vô hạn. Kiểm tra stdout/stderr và trạng thái, bấm Dừng và kiểm tra tác vụ kết thúc.

Áp dụng bản sửa AI rồi chạy lại. Sửa nguồn trong lúc chạy để kiểm tra nhãn bản cũ. Thử trên desktop và tab Viết mã điện thoại, kiểm tra ô nhập và nút không bị mất khỏi khung.
